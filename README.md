# Moghadam Theme — Documentation

This branch holds the documentation for the [Moghadam WordPress theme](https://github.com/moghadam-pro/moghadam-wp-theme).

It is an **orphan branch**: it shares no history with `main` and contains no theme
code. `main` holds the shippable theme and nothing else; everything about *why*
the theme is built the way it is lives here.
